# 复盘文档章节结构模板

交付载体：飞书在线文档（lark-doc，分析报告与决策支持体裁）。标题格式：【一面复盘/二面复盘】公司-岗位。章节用手写中文编号（一、二、…），"一图看懂"不编号。正文目标 3000-9000 字，由问题数量和材料复杂度决定。

## 章节结构

### 一图看懂（h1，不编号）
- 放置 html5-block 总评可视化（见 visualization.md 的 Block 1）
- 图后紧跟一段解释：核心判断 + 六维评分结论 + 三项改进方向

### 一、结论先行
- **面试性质与依据**：时间、时长、轮次、集中面/业务面、依据材料（面试记录 + 简历版本）
- **核心判断**：一句总评，如"项目素材强于现场呈现，AI 专项强于通用产品基本功的表达"
- **已建立的正向信号**（ul，3-5 条）：有证据支撑的亮点
- **主要失分点**（ol，5-6 条）：每条一句话点明问题本质
- **综合评价**（table：维度/评价/说明）：六维评分
- 收尾段：是否通过不做推断，注明逐字稿无明确正负反馈

### 二、简历锚点与岗位匹配
- **简历事实摘要**（ul）：教育、实习、项目、指标（脱敏联系方式）
- **简历亮点到面试问题的映射**（table：简历亮点/可证明能力/本轮关联问题/是否充分释放）
- **与公司岗位基线的匹配**：公司公开岗位要求 + 综合匹配度（x/10）+ 高匹配项/待补证项（ul 两组）

### 三、面试官能力模型
- table：能力维度 / 验证方式 / 本轮表现
- 从提问反推：职业动机、项目真实性、通用方法、差异化、用户数据意识、优先级抗压、公司认知

### 四、全程问题复盘
- **流程全景**：放置 html5-block timeline 可视化（Block 2）+ 图后解释段
- **逐题复盘**：每题一个 h3，标题带题号与时间区间
  - 每题固定结构：
    - 考察意图
    - 回答摘要
    - 评分（准确性｜完整性｜逻辑性｜表达力｜岗位匹配）
    - 有效之处
    - 问题（ul 或 p）
    - 优化版（blockquote，可直接背诵）
- **案例题答题框架对比**（有开放题时）：放置 html5-block 对比可视化（Block 3）+ 图后解释段

### 五、事实与口径账本
- table：Claim / 简历事实 / 面试表述 / 风险 / 下次统一口径
- 覆盖：项目成熟度、指标数字、责任边界、未释放亮点

### 六、简历问题诊断与修改建议
- **五维诊断**（ol）：数据缺失、技术深度、结果闭环、差异化、叙事结构
- **建议修改示例**：修改前（面试口径）blockquote + 修改后（事实边界更稳）blockquote
- **必做数据卡**（ul）：每个指标写清定义、分子/分母、样本、时间窗、来源、个人/团队动作、是否因果结论

### 七、2 分钟自我介绍优化稿
- blockquote 全文，结构：一句话定位 → B 端项目证据（量化）→ AgentOS/C端/独立项目 → 差异化两点 → 为什么这家公司

### 八、P0/P1 补强与复练计划
- **P0：下一场前必须完成**（ol）：口径统一、核心题 90 秒表达
- **P1：公司方向补强**（ol）：行业 Case、可验证优势、"为什么这家公司"
- **N 天安排**（table：天数/任务/完成标准）

### 九、下次回答原则
- ol：先答真正的问题、场景题先澄清目标约束、资源不够必须取舍、先说个人边界、数字绑定指标名、通用能力前置

### 十、事实、推断与仍需补充的数据
- **输入事实**（ul）：可核实的事实
- **分析推断**（ul）：明确标注为推断
- **仍需补充**（ul）：JD、后续流程、指标样本口径等

### 十一、原始材料索引
- 面试记录、简历路径、公司官网、岗位信息、公开资料（全部带链接与获取日期）

## 逐题复盘模板（每题）

```text
<h3>N. 问题名（时间段）</h3>
<p>考察意图：…</p>
<p>回答摘要：…</p>
<p>评分：准确性 x｜完整性 x｜逻辑性 x｜表达力 x｜岗位匹配 x</p>
<p>有效之处：…</p>
<p>问题：</p>
<ul><li>…</li></ul>
<p>优化版：</p>
<blockquote>可直接背诵的回答全文</blockquote>
```

## 评分体系

### 六维综合评价（总结级）
| 维度 | 考察点 |
|---|---|
| 项目真实性 | 能否讲清痛点/动作/结果，口径是否与简历一致 |
| 产品基本功 | 需求流程完整度、方案取舍、上线运营闭环 |
| 结构化思考 | 开放题/压力题是否框架化、结论先行 |
| 数据意识 | 指标定义是否前置、能否闭环验证 |
| 沟通表达 | 停顿、重复、抽象词、结论后置程度 |
| 岗位匹配 | 与目标岗位职责、公司业务的对口程度 |

### 五维逐题评分（题目级）
准确性、完整性、逻辑性、表达力、岗位匹配，每项 0-5 分。

## 数字处理规则
- 每个数字必须来自面试记录、简历或可核验来源；否则标注"待补充"并写明口径
- 面试与简历数字冲突时，以简历为准并在账本中标注风险
- 指标名必须精确：采纳率、一致率、命中率、通过率不得混用
