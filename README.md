# find-jobs-workflow

`find-jobs-workflow` 是一个用于求职全流程的 skill：帮助用户建立可复用背景档案，分析 JD、定制简历、识别短板、跟踪投递，并生成公司风格的面试备考材料。

## 它解决什么问题

求职里最容易重复、最容易混乱的几件事通常是：
- 不同 JD 下反复改简历
- 做过的经历没有被系统整理，临时回忆容易漏
- 投递记录零散，后续很难追踪
- 每次面试准备都从头开始
- 面试经验无法稳定沉淀到下一轮投递

这个 skill 的目标，就是把这些动作串成一套可复用流程。

## 当前覆盖的流程

1. 建立母版背景档案  
2. 深挖隐性经历并做项目分层  
3. 分析 JD，判断是否值得投递  
4. 生成岗位定制版简历  
5. 识别 hard gap / improvable gap / bonus gap  
6. 更新投递跟踪表  
7. 生成公司风格的面试问题与面试备考稿  
8. 衔接面试复盘 workflow  

## 适合什么时候用

适合这些场景：
- 你有一个新 JD，想知道值不值得投
- 你想针对某个岗位改简历
- 你想把过往经历整理成长期可复用的母版档案
- 你想跟踪已经投过的岗位
- 你想在简历生成后继续准备面试问题和备考稿

## 核心特点

- 不是只改简历，而是管理整个求职流程
- 不把所有经历平铺，而是做项目分层
- 支持同一段实习按不同 JD 切换叙事版本
- 生成简历后，继续生成公司风格的面试备考材料
- 默认把面试备考稿写入本地文件，而不是全部铺在对话框里
