# Output Templates

Use these templates as skeletons. Fill with user-specific content.

## 1) Pre-Interview Prep Guide (HTML)

Required sections:

- Header: company, role, round, generation date
- Resume highlights list
- Resume-job match report (score/high-match/low-match/prep advice)
- Interview flow overview (by round)
- High-frequency question bank
- STAR reference answers for priority questions
- Interviewer style summary
- Prep checklist (knowledge/project/soft skills/pitfalls)
- Simulation prompts
- Facts / Inferences / Data needed

## 2) Post-Interview Review Report (HTML)

Required sections:

- Header: role/company/date
- QA deep review (intent + five-dimension scores + issues + suggestions + STAR rewrite)
- Overall strengths and weaknesses
- Priority improvement list
- Learning path
- Resume diagnosis (5 mandatory dimensions)
- Resume before/after revision examples
- 2-minute self-intro optimization
- Resume revision checklist
- Facts / Inferences / Data needed

## 3) Multi-Interview Personal Guide (HTML)

Required sections:

- Header: analyzed interview count, target role(s), date
- Data overview cards (interviews, companies, total questions, repeated points)
- High-frequency topic list by priority
- Mastery labels (strong/medium/weak)
- SWOT summary
- Prioritized prep plan (urgent/important/long-term)
- Personalized question bank
- Recommended learning resources
- Facts / Inferences / Data needed

## Resume Revision Checklist

- All projects include measurable outcomes.
- Tech points include tool + scenario + method + effect.
- Project narrative forms full loop: background -> action -> result -> impact.
- Includes comparison/selection logic where relevant.
- Shows quality standards and validation process.
- Shows commercialization/growth thinking when applicable.
- Self-intro can be delivered in ~2 minutes with key metrics upfront.
- Resume wording is optimized for target role keywords.
